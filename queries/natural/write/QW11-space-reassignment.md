# QW11 - Space Reassignment

## Question
> **FR:** Comment réassigner un espace d'un locataire à un autre ?
>
> **EN:** How to reassign a space from one tenant to another?

## Cas d'usage / Use case
Réorganisation locataires, changement de surface.
Tenant reorganization, surface change.

## Paramètres / Parameters
| Nom | Type | Description | Exemple |
|-----|------|-------------|---------|
| SPACE_ID | string | ID de l'espace | `space_101` |
| OLD_TENANT_ID | string | ID de l'ancien locataire | `tenant_a` |
| NEW_TENANT_ID | string | ID du nouveau locataire | `tenant_b` |
